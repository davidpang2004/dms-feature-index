DMS.app

01

组织架构

让文件夹树真正贴合实际的工作结构——无论是一套设备总成、一个组织，还是一个家庭档案柜。

  • 层级文件夹树 — 按真实的总成、组织或归档结构搭建多级文件夹。
  • 拖拽排序或移动 — 移动文件夹时，磁盘上对应的真实文件会自动一起移动。
  • 每个文件夹可设序列号 — 在文件夹树内直接维护统一的资产/物料编号。
  • 回收站，而非彻底删除 — 删除的内容会进入"不在树中显示"回收站，可随时恢复。
  • 批量从文件夹移除 — 一次选中多份文档并从当前文件夹清除；无其他链接的会移入回收站，磁盘上的文件不会丢失。
  • 批量导入层级结构 — 通过简单的 CSV 格式定义文件，一次性建立成百上千个文件夹，也支持物料清单（BOM）中同一部件名合法地出现在不同上级下的情况。
  • 导入前预览 — 在真正创建之前，先检查导入的层级结构是否有误。
  • 磁盘上的真实文件夹 — 文件夹树会同步映射为磁盘上真实存在的文件夹，而不仅是数据库记录。
  • 照片根目录自动归档 — 指定一个文件夹，让新增照片自动按年、月归类。
02

采集与导入

拿到文件的那一刻，就应该能立刻存进去。

  • 拖放上传 — 直接从桌面或访达/资源管理器拖入文件。
  • 剪贴板粘贴 — Cmd/Ctrl+V 直接把截图粘贴进文件夹，无需先保存再上传。
  • 手机扫码采集 — 扫描二维码，用手机拍照，照片直接进入对应文件夹。
  • ZIP 批量导入 — 拖入一整个 ZIP 压缩包，DMS 自动把内容分类归档。
  • 按来源文件夹结构上传 — 上传一个或多个文件夹时，现在可以原样保留其子文件夹结构，而不是一律按日期自动归类。
  • 重复文件检测 — 上传时自动识别库中已存在的文件——可选择跳过、关联到已有文件，或仍然上传。
  • 支持 HEIC 格式 — iPhone 拍摄的照片无需手动转换即可正常预览。
  • 识别照片 EXIF 信息 — 读取照片的 GPS 位置与拍摄日期，并进行逆地理编码，自动按年、月、地点归档。
  • 自动识别文档日期 — 上传时读取文档首页上的日期并立即提出建议——随手确认即可，也直接为"趋势图表"（第 06 页）提供数据，无需额外录入。
  • 语音输入描述新增 — 录入照片或文档说明时可直接语音输入，识别结果自动转文字追加到描述中，支持带口音的普通话。
  • 上传上限提升至 4GB新增 — 原 1GB 限制在批量导入上万份文件时容易卡顿或失败，现已提升为 4GB，大批量导入导出更稳定。
03

查看与合并

无需离开浏览器即可阅读与整合文件。

  • 浏览器内直接预览 — PDF、图片、Office 文件均可直接打开，无需下载。
  • 完整的应用内 PDF 阅读器 — 支持翻页与缩放，并提供可容忍 OCR 错字的模糊"文档内查找"，直接跳转并高亮命中的页面位置。
  • 多份文档下载到指定文件夹 — 选中任意一组文档，复制到你指定的文件夹（默认是系统"下载"文件夹），完成后可选择直接打开该文件夹查看。
  • 在卡片上直接重命名文档 — 同步重命名磁盘上的文件与显示名称，无需额外步骤。
  • 合并为单个 PDF — 将选中的多份扫描件或文件合并为一个 PDF，并归档到指定文件夹；原始文件仍安全保留在存储中。快速合并会跳过正式封面页——仅靠逐文档书签即可导航——并自动将每一页统一转为竖版，即便原始页面是横版。
  • 一键用原生应用打开 — 交给系统默认的查看器或编辑器处理。
  • 拖拽即可关联已有文档新增 — 在"链接现有文档"窗口中，把搜索或浏览到的文档直接拖到目标文件夹上即可完成关联，无需逐一点击确认。
  • 当前文档持续高亮新增 — 打开一份文档后（无论用内置阅读器还是原生应用），它在所属文件夹列表中会保持高亮，方便随时定位。
04

搜索与数据提取

快速找到任何内容，并从扫描件中直接提取结构化数据。

  • 实时搜索 — 即时匹配文件名、OCR 识别文本与元数据。
  • 自动 OCR 识别 — 扫描版 PDF 与图片自动完成文字识别，支持多语言，遇到顽固扫描件可强制 OCR。
  • 乱码文本检测 — 自动识别不可靠的 OCR 结果，避免污染搜索结果。
  • 自定义关键参数提取 — 定义如"最大工作压力""序列号"等标签，从文档文本中直接提取对应数值。
  • 结构化提取结果 — 每条结果自动拆分为数值、单位、说明——而不是一整段原始文本。
  • 支持重复出现的关键字 — 同一标签在文档中多次出现时，会分别编号、单独提取。
  • 元数据 CSV 导出 — 每份文件及其元数据一行，直接可在 Excel 中打开。
  • 设计值 / 实测值双数据结构新增 — 每个关键参数可同时保存"设计值"与"实测值"，各自包含数值、单位与说明，便于合规核对与偏差分析。
  • 交互式预览浮窗新增 — 人工录入或核对参数时，可弹出一个可拖拽、可缩放的原文档预览窗口，边看原文边填写，无需来回切换页面。
05

AI 辅助

可选启用，使用自备的 API Key——专为普通搜索和正则表达式无法应对的文档而设计。

  • AI 驱动的关键参数提取 — 直接读取文档页面图像，提取传统文本匹配无法应对的复杂版式中的数值。
  • 全项目智能问答 — 用自然语言就整个项目（或单个文件夹）提问，获得带有原文引用来源的回答。
  • 引导式密钥配置 — 应用内提供获取并保存 Gemini API Key 的说明，密钥加密保存。
  • 接入 DeepSeek 大模型新增 — 除 Gemini 外，现可自由选择 DeepSeek 作为问答引擎，响应更快，更适合国内网络环境。
  • 问答记录自动整理为 PDF新增 — 每次向 AI 提问，问题与回答都会自动追加进一份随文档保存的 PDF 记录，随时可查、可搜索。
06

趋势图表

不离开文件夹，直接把一个重复出现的关键参数变成一张图表。

  • 参数-时间趋势图 — 选定一个文件夹和一个数值型关键参数（来自关键字提取或手动元数据），把每一份文档的数值按日期绘制成图，可选择是否包含子文件夹。
  • 自动生成时间轴 — 时间取自每份文档自身识别或录入的日期；若文档没有日期，则退而使用其所在的"YYYY-MM"文件夹名。
  • 点击图上的点即可打开文档 — 无论是图上的点还是下方表格中的一行，都可以直接跳转到对应的源文档。
  • Gemini 趋势点评 — 可选启用 AI，对趋势方向、大致变化速率及任何值得关注的异常值给出简明点评。
  • 图表窗口自由拖拽、缩放，还能弹出新增 — 图表不再固定居中：拖动标题栏可移动，拖边框可缩放，还能一键"弹出"为独立浏览器窗口，方便挪到另一台显示器上。
  • 坐标轴范围手动设置新增 — 横轴（时间）与纵轴（数值）都可在"自动"与"自定义"范围之间切换，切换到自定义时以当前自动范围为起点，随输入实时更新。
  • 两种年化收益率新增 — 点选一个基准点后，可显示各点相对基准点的年化收益率，或相邻两点之间的链式年化收益率，适合追踪账户余额、投资回报等财务类数据。
  • Excel 快照历史新增 — 点一下"保存快照"，把当天的日期与数值追加进按文件夹、按参数保存的 Excel 历史表；"总额-时间"图表可直接读取这份历史作图——适合手动记录、无法从文档中直接提取的累计余额一类数据。
07

照片与人脸识别

适用于照片和文书同样重要的资料库。

  • 标记一次人脸即可 — DMS 会自动建立"人物"目录，此后持续收录。
  • 点击人物即可查看全部照片 — "人物"视图汇总此人在整个库中出现过的每一张照片。
  • 自动扫描匹配 — 在某个文件夹或整个库中查找某位（或所有）已标记人物的更多照片，匹配置信度可调。
  • 一键安装识别引擎 — 引导式安装人脸识别底层引擎，并实时显示安装进度。
  • 彻底删除 — 一键删除某个人物及其全部标记。
  • 拍摄地点一键查看新增 — 照片带有定位信息时，一键即可在 Google 地图中查看拍摄地点。
08

资料手册生成（Databook）

一键把文件夹树变成一份可交付的装订文档。

  • 生成装订版 PDF 资料手册 — 从文件夹树中选取任意一组文件，自动生成封面、目录与分节书签。
  • 结构随文件夹树而定 — 文件夹顺序、序列号与路径自动成为资料手册的章节结构。
  • 可插入自定义封面 — 在自动生成的封面之前插入自己的封面页。
  • 自动处理纯图片章节 — 只含图片的文件夹会自动转换为可打印的 PDF 页面。
  • 自动转正竖版 — 横版原始页面会自动旋转为竖版显示，使合并后的资料手册全程保持统一的页面方向。
  • 大幅压缩含大量照片的输出文件 — 照片在嵌入前会智能重新压缩，在页面上观感几乎无损的前提下，把大量照片组成的资料手册体积压缩到原来的百分之一左右。
09

分享与远程访问

把一份文件——或者一个上传入口——交给不在同一台电脑前的人。

  • 发送到手机 — 生成一小时有效的下载链接，通过 iMessage/短信（Mac）或"你的手机"（Windows）发送，接收方无需安装任何应用。
  • 邮件发送 — 直接在应用内附件发送文件。
  • 远程上传链接 — 生成带二维码的公开链接，让同事或外部承包商无需账号即可从任何地方将文件直接上传到项目中。
  • 内置安全隧道 — 无需在本地做任何路由器或端口配置，远程链接即可使用。
  • 同一局域网直接访问 — 同一 Wi-Fi 下的其他设备可直接连接，完全不依赖互联网。
  • 手机浏览器直接浏览电脑文件新增 — 在手机浏览器打开同一条远程链接，即可像在电脑上一样浏览整棵文件夹树，而不只是接收单个文件。
10

备份与可迁移性

这里的一切都不会被"锁死"。文件始终是你的，格式也是任何软件都能打开的通用格式。

  • 真实文件，标准格式 — PDF、图片就是磁盘上普通文件夹里的普通文件，绝非专有格式的黑盒。
  • 免费获得云同步 — 把存储文件夹指向 OneDrive、Dropbox 或 iCloud，同步即自动完成。
  • 自动滚动备份 — 保留最近若干份备份，较旧的自动归档而不会被静默删除。
  • 灵活的手动导出 — 可选仅导出元数据、导出含全部文件的完整备份，或仅导出所选文件夹。
  • 受保护项目自动加密导出 — 设置了项目密码的项目（见第 11 页"安全与权限"）导出的每个 .dms 文件都会自动用该密码加密，无需再单独设置导出密码。
  • 导入与检查 — 可还原一份备份文件，也可以在真正导入前先查看其中内容。
  • 内置 OneDrive 配置指南 — 应用内提供分步设置说明。
11

安全与权限

既可以锁住整个资料库，也可以只保护其中敏感的部分。

  • 全局密码保护 — 可选的应用登录口令，保护本机上的整个应用，与当前打开哪个项目无关——加盐哈希存储。
  • 项目密码 — 一个独立于上面全局密码的第二重密码，只属于某一个具体项目——存储在项目文件夹内部，随文件夹一起复制、同步或交接。直接打开该项目，或在别处导入其导出的 .dms 文件，都需要这个密码。
  • 项目命名 — 为设有密码的项目起一个易识别的名称，会显示在其锁定界面和文件选择器中。
  • 按文件夹加密保存凭据 — 可将登录信息（网址、账号、密码）保存在特定文件夹下——例如某台设备的管理后台——只有点击"显示"时才会解密。
  • 分享链接自动过期 — 每条"发送到手机"链接一小时后自动失效。
  • 密钥全部加密存储 — API Key、文件夹密码、项目密码与邮箱凭据均不会以明文形式保存。
  • 单文件夹多组网站凭据新增 — 原来每个文件夹只能保存一组网站/账号/密码，现在可保存任意多组，并新增"复制用户名"按钮，无需再次连接服务器。
12

随处可用，中英双语

安装简单，日常使用更简单。

  • 一键桌面启动器 — 适用于 Mac 与 Windows，缺少的依赖会自动安装。
  • 完整中英双语界面 — 可随时一键切换语言。
  • 内置翻译版说明文档 — 设置指南与完整用户手册均可在应用内下载，中英文皆备。
  • 启动自愈 — 自动识别上一次异常退出遗留的进程并释放端口，而不会启动失败。

设备与现场记录

  • 扫码手机采集——拍下设备照片即自动归档
  • 按 GPS 与日期自动整理现场照片
  • 导入时按原有现场档案的文件夹结构原样保留
  • 为承包商提供无需账号的远程上传链接
  • 车间现场同局域网访问，无需联网
中小企业 / 行政

记录、合同、发票

  • 元数据 CSV 导出，方便记账
  • 全库密码之外，还可为敏感客户项目单独设密码
  • 发送到手机 / 邮件，快速交付给客户
  • 借助现有 OneDrive 或 Dropbox 免费备份，项目受保护时自动加密
家庭 / 个人

医疗、保险、遗嘱与日常文书

  • 医疗记录与 HSA/FSA 报销收据 — 自动 OCR 可搜索，几个月后也能轻松找到"3 月皮肤科账单 340 美元"，年底还可导出 CSV 用于报税
  • 保险单证 — 房屋、车辆、健康、人寿保险各建一个文件夹，保单号、保额、到期日自动提取
  • 遗嘱与预立医疗指示 — 单独设置项目密码，以加密的真实文件形式自动备份，关键时刻家人无需账号也能打开
  • 升学申请与日常文书 — 按孩子分文件夹，拖放扫描成绩单和表格，手机拍照上传无需安装任何 App
  • 人脸识别 — 按人物浏览家庭照片库，双语界面适合多语言家庭
摄影 / 活动

拍摄、相册、来宾照片

  • "人物"视图——标记一次，找到某人的全部照片
  • 一次性 ZIP 批量导入整场拍摄
  • 保留原有拍摄文件夹结构，而不是一律按日期重新归类
  • 按拍摄日期与地点自动整理
  • 将精选照片合并为一份可交付 PDF

01

Organize

A folder tree that mirrors how the work is actually structured — an assembly, a property, a family filing cabinet.

  • Hierarchical folder tree — build nested folders that match a real assembly, org, or filing structure.
  • Drag to reorder or move — the underlying files on disk move with the folder, automatically.
  • Serial number field per folder — keep consistent asset or item numbering built into the tree itself.
  • Recycle bin, not permanent delete — deleted items land in a "Not Show in Tree" bin and can be restored.
  • Bulk remove from a folder — select several documents and clear them from a folder in one action; anything left with no other link moves to the recycle bin, nothing is deleted from disk.
  • Bulk hierarchy import — build hundreds of folders in one pass from a simple CSV-style definition file, including bill-of-materials structures where the same part name legitimately repeats under different parents.
  • Preview before you commit — check an imported hierarchy for errors before it's created.
  • Real folders on disk — the tree is mirrored as an actual folder structure, not just a database record.
  • Photo-root auto-sorting — designate a folder that automatically files incoming photos by year and month.
02

Capture & Import

Getting documents in should be as easy as the moment you have them in hand.

  • Drag-and-drop upload — drop files straight from the desktop or Finder/Explorer.
  • Paste from clipboard — Cmd/Ctrl+V a screenshot directly into a folder, no save-then-upload step.
  • Mobile capture via QR code — scan a code, take a phone photo, and it lands straight in the right folder.
  • Batch ZIP import — drop in a whole ZIP archive and DMS sorts the contents into folders automatically.
  • Mirror an existing folder structure — uploading one or more folders can now recreate their exact subfolder layout inside DMS instead of auto-sorting everything by date.
  • Duplicate detection — flags files already in the library on upload — skip, link to the existing copy, or upload anyway.
  • HEIC support — iPhone photos preview correctly without a manual conversion step.
  • EXIF-aware photo filing — reads GPS and capture date from photos, with reverse geocoding, to auto-file them by year, month, and place.
  • Automatic document-date detection — the date on a document's own first page is read at upload time and proposed right away — ready to confirm, and ready to feed the trend charts (Sheet 06) with nothing extra to type.
  • Voice input for descriptionsNEW — dictate a photo or document's description — speech is transcribed and appended automatically, accented speech included.
  • Upload limit raised to 4GBNEW — the old 1GB cap could stall or fail on bulk imports of tens of thousands of files; raised to 4GB for steadier large-batch import and export.
03

View & Merge

Read and consolidate documents without leaving the browser.

  • In-browser preview — PDFs, images, and Office files open directly, no download required.
  • Full in-app PDF viewer — page navigation and zoom, plus a fuzzy "find in document" search that tolerates OCR typos and jumps straight to the highlighted match on the page.
  • Download several documents to a folder — select any set of documents and copy them out to a folder of your choice (the OS Downloads folder by default), with an option to reveal them when done.
  • Rename a document from its card — renames the file on disk and keeps the display name in sync, no separate step.
  • Combine documents into one PDF — merge any selected scans or files into a single PDF and file it back into a folder; originals stay safely in storage. Quick merges skip the formal cover page — per-document bookmarks alone handle navigation — and every page is normalized to portrait even when a source page is landscape.
  • Open in native app — one click hands a document off to the default OS viewer or editor.
  • Drag to link an existing documentNEW — in "Link existing document," drag a search or browse result straight onto a target folder to attach it — no per-item confirm click needed.
  • Persistent current-document highlightNEW — opening a document (in the viewer or a native app) keeps it highlighted in its folder's list, so it's easy to find again.
04

Search & Data Extraction

Find anything, and pull structured data straight out of a scanned page.

  • Live search — filters instantly across filenames, OCR'd text, and metadata.
  • Automatic OCR — scanned PDFs and images get OCR'd on the spot, multi-language, with a force-OCR override for stubborn scans.
  • Garbled-text detection — catches bad OCR output before it pollutes search results.
  • Custom key-parameter extraction — define labels like "Max Working Pressure" or "Serial No." and pull their values straight out of a document's text.
  • Structured results — each match is split into value, unit, and description — not one raw text blob.
  • Repeated-key handling — a label that appears more than once in a document is captured as separate, numbered results.
  • CSV metadata export — every document and its metadata, one row each, ready to open in Excel.
  • Design-value / actual-value pairNEW — each key parameter can hold both a "design" and an "actual" reading, each with its own value, unit, and description — ready for compliance checks and deviation analysis.
  • Interactive preview flyoutNEW — while entering or double-checking a parameter by hand, pop open a draggable, resizable preview of the source document — no more tabbing back and forth.
05

AI Assist

Opt-in, bring-your-own API key — for the documents plain search and regex can't handle.

  • AI-powered key extraction — reads a document's actual page images to pull key values out of layouts that defeat text-pattern matching.
  • Ask AI across the whole project — ask a plain-language question over every document (or one folder) and get an answer with citations back to the source files.
  • Guided key setup — in-app instructions for getting and saving a Gemini API key, encrypted at rest.
  • DeepSeek model addedNEW — choose DeepSeek alongside Gemini as the Q&A engine — faster and steadier for users on mainland China networks.
  • Q&A history saved automaticallyNEW — every question and answer is appended to a running PDF log kept alongside the document — searchable, and always there later.
06

Trend Charts

Turn a repeated key parameter into a chart, without leaving the folder it lives in.

  • Parameter vs. time chart — pick a folder and a numeric key parameter (from key extraction or manual metadata) and see every value plotted against date, optionally including subfolders.
  • Automatic timeline — dates come from each document's own detected or entered date, or — failing that — from the "YYYY-MM" folder it's filed under.
  • Click a point, open the document — jump straight from a plotted value, or a row in the table beneath it, to the source document.
  • Gemini trend commentary — opt-in AI read on the trend's direction, approximate rate of change, and any outliers worth a second look.
  • Free-floating, resizable — and pop-out — chart windowNEW — no longer fixed and centered: drag the header to move it, drag an edge to resize, or pop it out into its own browser window to drag onto a second monitor.
  • Manual axis rangesNEW — toggle either axis between Auto and Custom; switching to Custom starts from the current auto-fit range and updates live as you edit it.
  • Two annualized-return modesNEW — pick a point as the baseline to see every other point's annualized return against it, or a chained point-to-point annualized return — built for tracking account balances and investment returns.
  • Excel snapshot historyNEW — one click on "Save snapshot" appends today's date and value to a per-folder, per-parameter Excel history file; "Total vs. time" reads it straight back into a chart — ideal for a running balance that isn't extracted from any single document.
07

Photos & Face Recognition

For libraries where the photos are as important as the paperwork.

  • Tag a face once — DMS builds a People directory automatically from that point on.
  • Click a person, see every photo — the People view collects every appearance across the library.
  • Auto-scan for matches — find more photos of a tagged person (or everyone) in a folder or the whole library, with an adjustable match-confidence threshold.
  • One-click engine setup — guided installer for the underlying face-recognition engine, with live progress.
  • Clean removal — delete a person and every one of their tags in a single action.
  • One-click shooting locationNEW — for GPS-tagged photos, jump straight to the shooting location on Google Maps.
08

Databook Output

Turn a folder tree into a bound handoff package, in one click.

  • Generate a bound PDF databook — from any set of documents across the tree, with an auto-built cover page, table of contents, and per-section bookmarks.
  • Structure follows your tree — folder order, serial numbers, and paths become the databook's section structure.
  • Custom front page — insert your own cover ahead of the auto-generated one.
  • Photo sections handled automatically — image-only folders convert into print-ready PDF pages.
  • Automatic portrait normalization — a landscape source page is rotated to display upright, so a merged databook holds one consistent orientation throughout.
  • Compact photo-heavy output — images are intelligently re-compressed before embedding, cutting the file size of a photo-heavy databook by two orders of magnitude with no visible loss on the page.
09

Share & Remote Access

Get a document — or a whole upload point — to someone who isn't in front of the same computer.

  • Send to Phone — generates a one-hour download link and texts it via iMessage/SMS (Mac) or Phone Link (Windows) — no app needed on the receiving end.
  • Send by email — attach and send a document directly from the app.
  • Remote Upload link — a public link with a QR code that lets a colleague or contractor upload straight into the project from anywhere, no account required.
  • Built-in secure tunnel — remote links work with no router or port configuration on your end.
  • Same-network access — other devices on the same Wi-Fi connect directly — no internet dependency at all.
  • Browse the full tree from a phone browserNEW — open the same remote link on a phone and browse the whole folder tree as if at the computer — not just receive one file at a time.
10

Backup & Portability

Nothing here is locked in. The files are yours, in formats anything can open.

  • Real files, standard formats — PDFs and images sit in normal folders on disk, never a proprietary blob.
  • Cloud sync for free — point the storage folder at OneDrive, Dropbox, or iCloud and syncing just happens.
  • Automatic rolling backups — the most recent backups are kept, older ones auto-archived rather than silently deleted.
  • Flexible manual export — metadata only, a complete backup with every file, or just selected folders.
  • Encrypted exports for protected projects — a project with its own password (see Security, Sheet 11) has every .dms export automatically encrypted with it — no separate export password to set.
  • Import and inspect — restore a backup file, or check what's inside one before committing to the import.
  • Guided OneDrive setup — step-by-step instructions built into the app.
11

Security & Access

Lock down the whole library, or just the sensitive parts of it.

  • Library-wide password — optional login screen protecting the entire application, on this machine, regardless of which project is open — salted and hashed.
  • Per-project password — a second, independent password that belongs to one specific project — stored inside its own folder, so it travels along on a copy, a sync, or a handoff. Required to open that project directly, or to import its exported .dms file anywhere else.
  • Named projects — give a password-protected project a friendly name, shown on its lock screen and in the file picker.
  • Per-folder credential storage — save a login (URL, account, password) against a specific folder — e.g. an equipment portal — decrypted only when you click reveal.
  • Self-expiring share links — every "Send to Phone" link stops working after one hour.
  • Secrets encrypted at rest — API keys, folder passwords, project passwords, and email credentials are never stored in plain text.
  • Multiple logins per folderNEW — a folder used to hold one website/username/password; now it can hold any number, with a one-click "copy username" that doesn't round-trip to the server.
12

Runs Anywhere, Speaks Two Languages

Low-friction install, low-friction daily use.

  • One-click desktop launcher — for Mac and Windows, installs its own missing dependencies automatically.
  • Fully bilingual UI — Chinese and English throughout, switchable instantly.
  • Translated guides, in-app — setup instructions and a full user manual, downloadable in either language.
  • Self-healing launch — detects a stale or crashed prior session and clears the port automatically, rather than failing to start.
